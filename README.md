# Resume

Personal resume site. Built with Astro and Tailwind CSS 4.

Live at [niconisoria.github.io/resume](https://niconisoria.github.io/resume/).

## Commands

| Command                | Action                                            |
| :--------------------- | :------------------------------------------------ |
| `npm install`          | Install dependencies                              |
| `npm run dev`          | Start local dev server at `localhost:4321`        |
| `npm run build`        | Build production site to `./dist/`                |
| `npm run preview`      | Preview production build locally                  |
| `npm run astro check`  | Type-check project                                |
| `npm test`             | Run tests (Vitest)                                |
| `npm run lint`         | Lint (ESLint)                                     |
| `npm run format`       | Format (Prettier)                                 |
| `npm run format:check` | Check formatting without writing                  |
| `npm run pdf`          | Regenerate `public/resume/nicolas-nisoria.pdf`    |
| `npm run mock:chat`    | Local `/chat` mock for the dev server (port 8787) |

See `CLAUDE.md` for project structure, iron laws, and docs.
